# OPIMS---oceanic-pulse-induction-metal-sensing-3D-design
O-PIMS (Oceanic Pulse Induction Metal Sensing) is a low-cost, deployable seafloor sensing system for preliminary detection and mapping of potential metal-rich zones. This 3D model shows its pressure housing, structural frame, PI coil, sonar, camera, sensors, and buoyancy-assisted recovery mechanism.
